# 🍔 JG Food

**JG Food — Discover. Order. Enjoy.**

JG Food is a modern food-delivery web application designed to help users discover restaurants, browse menus, add meals to their cart, place orders, save favorite restaurants, and manage their delivery information.

## 🚀 Features

- 🍽️ Restaurant discovery
- 🔎 Food and restaurant search
- 📋 Restaurant menus
- 🛒 Shopping cart
- ❤️ Favorite restaurants
- 📦 Order history
- 👤 Account section
- 📍 Delivery location
- 🌙 Dark & Light mode
- 💾 Local Storage
- 📱 Responsive design
- 💰 Nigerian Naira (₦) pricing

## 🏪 Restaurants

The current version includes:

- 🍔 Burger District
- 🍛 Mama's Kitchen
- 🍕 La Pizza House
- 🍗 Chop & Grill
- 🍜 Noodle Bowl
- 🍰 Sweet Spot
- 🥤 Fresh Sip

## 🛒 Ordering System

Users can:

1. Browse restaurants
2. Open a restaurant
3. View the menu
4. Select a meal
5. Choose quantity
6. Add the meal to cart
7. Review the cart
8. Enter delivery details
9. Select a payment method
10. Place an order
11. View previous orders

## 🌙 Theme

JG Food supports both:

- ☀️ Light Mode
- 🌙 Dark Mode

The selected theme is saved in the browser.

## 💾 Local Storage

The application currently stores the following information locally:

- Cart
- Orders
- Favorites
- Delivery location
- Theme preference
